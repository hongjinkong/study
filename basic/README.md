# Python 기초

Jupyter Notebook을 사용해 Python의 기본 문법과 자료구조를 순서대로 학습한 예제입니다.

## 학습 순서

| 노트북 | 주요 내용 |
| --- | --- |
| `1.변수.ipynb` | 변수 선언, 자료형, 값 저장 |
| `2.문자열.ipynb` | 문자열 생성, 인덱싱, 슬라이싱, 문자열 함수 |
| `3.연산자.ipynb` | 산술·대입·비교·논리 연산자 |
| `4.조건문.ipynb` | `if`, `elif`, `else`와 조건식 |
| `5.리스트.ipynb` | 리스트·튜플, 추가·수정·삭제, 인덱싱과 슬라이싱 |
| `6.반복문.ipynb` | `for`, `while`, 반복 제어 |
| `7.딕셔너리.ipynb` | Key-Value 구조, 조회, 반복, 삭제 |
| `8.함수.ipynb` | 함수 정의, 매개변수, 가변 인자, 여러 반환값, 독스트링 |
| `AI에이전트_홍진성.ipynb` | 기초 문법을 활용한 종합 실습 |

## 실행 방법

```bash
python -m venv .venv
source .venv/bin/activate
pip install jupyter
jupyter notebook
```

Windows에서는 가상환경 활성화 명령으로 `.venv\Scripts\activate`를 사용합니다.

## 복습 포인트

- 변수의 자료형과 변경 가능 여부를 구분합니다.
- 리스트, 튜플, 딕셔너리의 사용 목적을 비교합니다.
- 반복문과 조건문을 결합해 데이터를 처리합니다.
- 중복되는 로직은 함수로 분리하고 입력값과 반환값을 명확히 합니다.
