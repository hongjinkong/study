# study

AI 에이전트 엔지니어 부트캠프 학습 기록입니다. Python 기초부터 데이터 분석, 머신러닝/딥러닝, 텍스트 마이닝, 웹, 배포까지 공부하며 작성한 코드와 노트북을 모아둔 저장소입니다.

## 폴더 구성

| 폴더 | 내용 |
|------|------|
| `basic` | Python 기초 (변수, 문자열, 연산자, 조건문, 리스트, 반복문, 딕셔너리, 함수) |
| `python_library` | 파이썬 라이브러리 실습 |
| `DB` / `sqldeveloper` | 데이터베이스 · SQL 실습 |
| `web` | 웹 기초 |
| `웹 크롤링` | 웹 크롤링 실습 |
| `machine learning` | 머신러닝 실습 |
| `deep learning` | 딥러닝 실습 (이진/다중 분류, 오차 역전파 등) |
| `실데이터분석` | 실제 데이터 분석 프로젝트 (카페 매장, 개발자 연봉 등) |
| `텍스트마이닝` | 자연어 처리 · 감정 분석 (Word2Vec 등) |
| `streamlit` | Streamlit 앱 실습 |

## 참고

용량이 크거나 재생성 가능한 파일(설치 프로그램, 모델 가중치, 대용량 데이터셋/이미지, 압축 파일 등)은
`.gitignore`로 제외했습니다. 데이터가 필요한 노트북은 원본 데이터를 별도로 준비해야 합니다.
